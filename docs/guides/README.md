# vaporTV guides

How to get things working in vaporTV. The same guides are built into vaporTV, under
**Settings → Help → Guides**, each with a QR code that opens it here on your phone.

1. [Streaming apps](streaming-apps.md): Netflix, Disney+, YouTube, Plex, Kodi and the rest
2. [Emulators](emulators.md): EmuDeck, where games go, and each console's tab
3. [The Netflix extension](netflix-extension.md): Moving around Netflix with a remote or D-pad
4. [TV remotes](remotes.md): Pairing, the buttons, and waking the box
5. [When an update breaks something](updates.md): Repairs, and updating vaporTV
6. [Privacy](privacy.md): What vaporTV sends where, what it keeps, and clearing it

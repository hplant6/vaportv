4. [The Netflix extension](netflix-extension.md): Moving around Netflix with a remote or D-pad
5. [TV remotes](remotes.md): Pairing, the buttons, and waking the box

7. [Privacy](privacy.md): What vaporTV sends where, what it keeps, and clearing it
